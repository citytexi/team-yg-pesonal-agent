# Spec: G-001 그룹 목록 화면 (GroupList)

> as-built 역기록이고 **코드가 SoT**다. 위키 정책 [[무한-파르페-그리드]]·[[g-001-empty-툴팁]]과 대조했고,

- **화면 ID**: G-001 (그룹 목록 — 무한 파르페 메인 화면)
- **대상 모듈**: `feature/groups/list/impl`(+`api`의 `NavKeyGroupList`) · `core:designsystem`(`ygtopbar/`) ·
  `core:util:android`(`extension/`) · `core:util:jvm`(`model/`)

## 목표

앱 진입 후 소속 그룹을 파르페 메타포로 보여주는 메인 화면. 이번 라운드는 **화면 골격**(상단 바 ·
날짜 · 파르페 배경 · 그룹 추가 오버레이 · 온보딩 툴팁)까지고, **그룹 데이터·토핑 배치는 들어오지 않았다**.

## 범위

- 포함
  - 배경 이미지 + 상단 바(`YGTopBarEmpty` + 우측 "그룹 추가하기" 칩)
  - 오늘 날짜 표시(`YGDate`)
  - 파르페 세로 스택 레이아웃(`GroupListParfaitLayout`, `SubcomposeLayout`)
  - 온보딩 툴팁(`GroupListTooltip` + Material3 `TooltipBox`)
  - 그룹 추가 오버레이(`GroupListAddGroupScreen` — "그룹 만들기" / "그룹 들어가기")
  - 사이드 메뉴(S-001)·초대코드(G-002) 이동 결선
- 제외(구현 TODO)

  - **캔버스(C-001) 이동** — `NavigateToCanvas`가 주석 TODO
  - **그룹 생성(A-005) 이동** — `NavigateToCreateGroup`이 주석 TODO(`NavKeyGroupCreate` 미결선,

## API / 인터페이스

```kotlin
// impl — MVI
data class GroupListUiState(
    val groupList: List<String> = emptyList(),   // Todo : 임시로 String 으로 설정
    val groupAddButtonSelected: Boolean = false, // 그룹 추가 오버레이 노출
    val isTooltipVisible: Boolean = false,       // 현재 렌더에 미사용(아래 주의)
    val dateString: String = "",
    val dayOfWeekString: String = "",
) : UiState

sealed interface GroupListIntent : UiIntent {
    data object ClickTopBarChip; data object DismissedTopBarChip
    data object ClickCreateNewGroup; data object ClickEnterNewGroup
    data object ClickSideMenu; data object ClickTopping
}
sealed interface GroupListSideEffect : UiSideEffect {
    data object NavigateToAppSideMenu; data object NavigateToCanvas
    data object NavigateToCreateGroup; data object NavigateToInviteCode
}

@HiltViewModel
class GroupListViewModel @Inject constructor() : BaseViewModel<…>(GroupListUiState())
```

- 인자 없는 `data object NavKeyGroupList`라 Assisted 주입이 아니다(생성자 의존 0).
- 날짜는 VM `init`에서 `Clock.System.now()`를 기기 타임존 `LocalDate`로 접어 `DateFormat` 두 포맷으로 산출.
  화면은 이미 만들어진 문자열만 받는다.

### 신설 공용 유틸

| 심볼 | 모듈 | 용도 |
|---|---|---|
| `DateFormat.FullMonthWithDay` / `.AbbreviatedDayOfWeek` | `core:util:jvm` `model/` | `kotlinx-datetime` `LocalDate.Format` 2종(영문 월+일 / 영문 요일 약어) |
| `Modifier.drawTooltipCornerTop(...)` | `core:util:android` `extension/` | 툴팁 상단 말풍선 꼬리. 바깥 삼각형(테두리색) 위에 안쪽 삼각형(배경색)을 덮어 선처럼 보이게 함 |
| `AnnotatedString.Builder.withStyle(textStyle) { }` | `core:util:android` `extension/` | `TextStyle` → `SpanStyle` 변환을 감춘 오버로드 |

## 동작 / 상태

- **사이드 메뉴**(`ClickSideMenu`) → `NavigateToAppSideMenu` → `goTo(NavKeyAppSetting)`.
- **그룹 추가 칩**(`ClickTopBarChip`) → `groupAddButtonSelected = true` → 오버레이 노출.
  오버레이 바깥(=오버레이 루트 `Column`) 클릭 → `DismissedTopBarChip` → false.
- **그룹 만들기**(`ClickCreateNewGroup`) → `NavigateToCreateGroup`(TODO stub).
- **그룹 들어가기**(`ClickEnterNewGroup`) → `NavigateToInviteCode` → `goTo(NavKeyGroupInviteCode)`.
- **토핑 클릭**(`ClickTopping`) → `NavigateToCanvas`(TODO stub). 현재 이 인텐트를 발신하는 UI가 없다.
- **툴팁**: `rememberTooltipState(initialIsVisible = false, isPersistent = true)`를 화면이 직접 들고
  `LaunchedEffect(Unit) { show() }`로 **진입 시 무조건** 띄운다. 그룹 보유 수와 무관하다.

## 표시·제어 규칙

### 화면 컨테이너 (⚠️ 규약 이탈)

```
entry<NavKeyGroupList> {
    Box(fillMaxSize, background = Gray.White) {
        Image(group_list_background, ContentScale.Crop, fillMaxSize)
        GroupListRoute(...)
    }
}
GroupListRoute {
    YGScaffold(containerColor = Gray.Transparent) { GroupListScreen(...) }
    if (groupAddButtonSelected) YGScaffold(containerColor = Transparency.Black25) { GroupListAddGroupScreen(...) }
}
```

- 엔트리 컨테이너가 `YGScaffold`가 아니라 `Box`이고(배경 이미지를 nav 레벨에서 깔기 위함),
  `YGScaffold`는 Route 안으로 내려갔다. 오버레이(Dim)도 **두 번째 `YGScaffold`**로 겹쳐 그린다.
- 화면 최외곽 `YGScreen`을 쓰지 않는다 → `YGScreenScope.OnBack` 경로도 없다.
- [navigation-flow](../../architecture/navigation-flow.md) 체크리스트·[design-system](../../architecture/design-system.md)
  "화면 컨테이너" 역할 분리와 어긋난다 → [open-questions](../../synthesis/open-questions.md) [2026-08-01].

### 본문

- `Column` — `YGTopBarEmpty` + `LazyColumn`(좌우 `padding7`, 하 `padding6`).
- 상단 바는 `YGTopBarEmpty(date = uiState.dateString, day = uiState.dayOfWeekString, …)` — 날짜 두 값은
  #188에서 상단 바가 파라미터로 받게 되면서 결선됐고, 그 전까지 상단바만 고정 문자열이었다.
  `hazeState`는 넘기지 않아 **배경 블러는 꺼진 상태(틴트만)**다.
- 상단 바 우측 슬롯(`rightContent`)에 `TooltipBox`로 감싼
  `YGChipButton(stringResource(R.string.group_add), GrayOutline, ic_plus)`(칩 프리셋은 #188에서 교체·개명,
  문자열은 #189에서 리소스화).
  툴팁은 칩 **아래**(`TooltipAnchorPosition.Below`)에 붙고 `enableUserInput = false`라 롱프레스·호버로는 뜨지 않는다.
- 첫 아이템 `YGDate(date = dateString, day = dayOfWeekString)`, 이어서 `GroupListContent()`.

### 파르페 레이아웃 — `GroupListParfaitLayout`

`SubcomposeLayout`으로 `cherry → top → middle* → bottom`을 **가운데 정렬 세로 스택**한다.

- 각 이음매를 겹침 상수만큼 당긴다: `CherryOverlap`·`TopOverlap`·`MiddleOverlap`·`BottomOverlap`
  (`GroupListParfaitDefaults`, 호출자 override 가능).
- `content` 슬롯(그룹 토핑이 들어갈 자리)의 높이가 스택 높이보다 크면, 덮을 때까지 **`middleSection`을
  올림 나눗셈으로 반복 서브컴포즈**한다. 겹침을 뺀 실증가분(`middleStep`)이 0 이하면 반복하지 않는다(무한 루프 방어).
- z: 체리·top·bottom은 `FRONT`, middle은 뒤로 갈수록 `FRONT - n`(앞선 크림이 위), `content`는 최상단.
- 현재 호출부(`GroupListContent`)는 4개 슬롯에 파르페 드로어블만 넣고 **`content`를 비운다** —
  즉 지금은 크림 1칸짜리 정적 파르페다.
- 에셋은 `feature/groups/list/impl` `res/drawable`에 있다(`parfait_cherry`·`parfait_cream_top`·
  `parfait_cream_default`·`parfait_cup`·`group_list_background`). 디자인시스템이 아니라 화면 소유다.

### 툴팁 — `GroupListTooltip`

- 흰 배경 + `Melon500` 테두리 + `drawTooltipCornerTop` 꼬리(우측에서 일정 거리로 앵커).
- 문구는 `buildAnnotatedString`으로 "새 그룹"·"그룹에 참여"만 `body.b02B`/`Melon600` 강조, 나머지는 `b02R`/`Black`.
- 문구가 컴포저블 안 **리터럴**이고, 위키 정책은 문구·앵커를 미정으로 둔 상태다(아래 대조 표).

### 그룹 추가 오버레이 — `GroupListAddGroupScreen`

- 우측 정렬 `Column`(루트에 `clickableYG(onDismissed)`) — 상단에 칩 모양을 한 번 더 그리고(비활성 `onClick = {}`),
  아래에 `Cherry50` 배경 `medium1` 라운드 메뉴 카드.
- 카드 = `YGActionItem("그룹 만들기", ic_new_group)` + `YGHorizontalDivider` + `YGActionItem("그룹 들어가기", ic_enter)`.
- `ic_new_group`은 이번 라운드 신설 드로어블(`core:designsystem` `res/drawable`).
