## 핵심 요점
- **초기 자동 생성 규칙 (v0.2 신규)**: 계정 생성 시 **1회**, 형용사/동사 + 파르페 재료 랜덤 조합으로 앱 닉네임 자동 부여. 조합 형식 **공백 없이 붙여씀**(`녹는딸기`, `몽글한푸딩`). 계정 생성 즉시 저장, **재계산 없음**. 단어 풀 100×30은 이 문서에선 **노션 참조**로만 남음 — 실물은 [[S-002-앱-닉네임-생성-정책-v0.1]]이 수록.
- **허용 문자**: 한글·영문·숫자·공백. 특수문자·이모지 불가.
- **글자 수**: 최소 1자 ~ 최대 **15자**. 공백도 1글자 카운트.
- **공백**: 앞뒤 불가, 중간 1칸만, 연속 불가.
- **적용 범위**: 앱 닉네임은 **자동 생성 규칙 우선** → **사용자가 수정하는 시점부터** 유효성 규칙 적용.
- 개인정보: 작성자·예시 실명 마스킹(더미 `홍길동`).

## v0.1 → v0.2 변경
- **초기 자동 생성 규칙 신설**이 유일한 실질 추가분(원문 개정이력: "초기 닉네임 생성 규칙 추가").
- 유효성 규칙 3종·입력 예시는 v0.1과 **문자 그대로 동일**, 번호만 1~3 → 2~4로 재편.
- 적용 범위 서술 정교화: v0.1 "초기 랜덤 닉네임 수정 시점부터 적용" → v0.2 "자동 생성 규칙이 **우선 적용**되고 이후 수정 시점부터 유효성 규칙 적용".
- [[S-102-닉네임-정책-v0.2]]와 같은 시점·같은 내용의 화면별 판본이다.
