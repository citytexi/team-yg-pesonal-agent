## 핵심 요점
- **초기 자동 생성 규칙 (v0.2 신규)**
  - 계정 생성 시 **1회**, **형용사/동사 + 파르페 재료** 랜덤 조합으로 **앱 닉네임 자동 부여**.
  - 조합 형식 = **공백 없이 붙여씀** (예: `녹는딸기`, `몽글한푸딩`).
  - 계정 생성 즉시 저장, **이후 재계산되지 않음**.
  - 단어 풀 = **형용사/동사 100개 · 파르페 재료 30개**(조합 3000). 이 원문은 목록을 **노션 참조**로만 남겼고, 실물은 [[S-002-앱-닉네임-생성-정책-v0.1]]이 수록(2026-07-29 수집) → [[닉네임-자동-생성]].
- **허용 문자**: 한글·영문·숫자·공백(스페이스바)만. 특수문자·이모지 불가.
- **글자 수**: 최소 1자 ~ 최대 **15자**. 글자 사이 공백도 **1글자로 카운트**.
- **공백**: 맨 앞·맨 뒤 불가. 중간 공백 **1칸만** 허용, 연속 공백 불가.
- **적용 범위**: 그룹 내 닉네임 / 앱 닉네임 — 앱 닉네임은 **계정 생성 시 자동 생성 규칙이 우선**, **사용자가 수정하는 시점부터 유효성 규칙(허용 문자·글자 수·공백) 적용**.
- 개인정보: 작성자·예시 실명 마스킹(더미 `홍길동`).

## v0.1 → v0.2 변경
- **§1.1 초기 자동 생성 규칙 신설** — v0.2의 유일한 실질 추가분(원문 개정이력: "초기 닉네임 생성 규칙 추가").
- 규칙 번호 재편: v0.1의 1~3(허용 문자·글자 수·공백) → v0.2의 2~4. **내용은 문자 그대로 동일**.
- 적용 범위 서술 정교화: v0.1 "초기 랜덤 닉네임 수정 시점부터 적용" → v0.2 "초기 자동 생성 규칙이 **우선 적용**되고, 이후 사용자가 수정하는 시점부터 **2~4번 유효성 규칙 적용**"(자동 생성물은 유효성 검사 대상이 아님을 함의).
- 입력 예시 가이드는 v0.1과 동일.
