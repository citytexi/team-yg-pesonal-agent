## 핵심 요점
- **Canvas 구성 모델 신설**: `Canvas = Canvas-Area + Canvas-Menu`. Bottom-Bar는 Canvas-Area 하단에 gap 없이 붙어 Canvas의 일부. **별도 탭바 없음**(Bottom-Bar가 Canvas 최하단 요소). Bottom-Bar 고정 높이·**16:9 계산 제외**.
- **16:9 대상 변경**: **Canvas-Area만 16:9** 유지(Canvas-Menu는 고정 높이 별도 추가). `Canvas 전체 높이 = Canvas-Area(16:9) + Canvas-Menu 고정 높이`.
- **좌상단 컷 도형 + 날짜 라벨(Button-Date-Select)**: 좌상단 모서리 비스듬히 잘린 장식 컷. 라벨은 컷 위에 표시, 반투명 뒷영역까지 캔버스 영역 포함. 위치 캔버스 카드 상단 고정, 높이 고정, 너비는 캔버스 따라 변화(내부 좌우 패딩 고정). **저장 시 컷·라벨 미반영 → 완전 사각형으로 저장**.
- **배치**: 상단 고정 요소 하단~화면 최하단(홈 인디케이터) 사이 세로 중앙 정렬, 상·하단 갭 동일 최소 12px, Top Bar↔Canvas·Canvas↔최하단 각 최소 gap 12px, 좌우 패딩 20px(예외 시 캔버스 축소·패딩 20px 초과). 내부 요소 비례 스케일.
- **Background-Dot-Grid 신설**: 점 2px·Gray-100·간격 20px, (0,0) 앵커 타일링. 화면 커져도 **점 크기·간격 고정, 개수 증가**(스케일 X). 화면 전체 뒤에 깔림 — 캔버스 영역은 배경색이 덮어 가려지고, 여백 영역은 그대로 노출.

## v0.1 → v0.2 변경 / 미해결
- **탭바 → Bottom-Bar 재정의**: v0.1 "하단 탭바 플로팅 고정" → v0.2 별도 탭바 없이 Bottom-Bar가 Canvas 내 최하단 요소로 편입. (버전 진화)
- **16:9 적용 범위 축소**: v0.1 캔버스 전체 16:9 → v0.2 Canvas-Area만.
- ⚠️ **Background Blur(v0.1 §2) 존폐 불명확**: v0.2 원문에 Blur 언급 없음. Dot Grid로 대체인지 병존인지 미확정 → [[open-questions]].
