# 누끼 이미지 정책 (C-103-Selected · 객체 선택 영역) v0.1

- **원본**: `raw/C-103-Selected-누끼-이미지-정책-v0.1.md`
- **날짜**: 2026-07-23 (작성자 DSN-A)
- **도메인**: product
- **적용 화면**: C-103-Selected(누끼 대상 선택) 기준 캔버스 생성 → **C-103~C-105 동일 스케일 전달** ([[기능정의서-v6]])

## 핵심 요점
- **캔버스 생성(데이터 영역)**: 객체만 잘라내지 않고 **여백 포함 '캔버스'** 생성 → C-105까지 동일 스케일 전달(이후 영역 채우기·테두리 편집 용이).
  - 기준: 대상 객체의 **최소 바운딩 박스**(타이트한 점선 영역).
  - **안전 여백**: 바운딩 박스 상하좌우 **+20%**(또는 지정 고정 px) 추가.
  - **예외(가장자리 객체)**: 여백만큼 뻗을 사진 데이터가 없으면 부족분을 **투명 픽셀(Alpha 0%)로 강제 확장** → 캔버스 크기 동일 유지.
- **화면 노출(UI 렌더링, C-103~C-105)**:
  - **Max Bounding Box**: 너비 `Device Width − 40px`, 높이 `Device Height − (상단 UI + 10px) − (하단 UI + 16px)`.
  - **스케일링**: 캔버스 전체(객체+여백) 비율 100% 유지, **Aspect Fit(`object-fit: contain`)**, 남는 여백에서 **정중앙 배치**.

## 참고
- 화면 노출부의 Max Bounding Box 공식은 [[이미지-렌더링-정책]](공용)과 동일. 단 이 정책은 **객체+여백 캔버스 전용**(Aspect Fit contain), 공용 정책은 일반 이미지 단독 노출(Case A/B 분기). 상충 아님.
