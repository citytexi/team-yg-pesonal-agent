# 이미지 렌더링 정책 (공용) v0.1

- **원본**: `raw/C-103-이미지-렌더링-정책-v0.1.md`
- **날짜**: 2026-07-09 (작성자 DSN-A)
- **도메인**: product
- **성격**: **공용 정책 — 특정 화면 번호 비종속**. 이미지 단독 노출 화면(C-101-confirm·C-102-confirm·C-103 계열)에 공통 적용 ([[기능정의서-v6]]).

## 핵심 요점
- **Max Bounding Box**:
  - 최대 너비 = `Device Width − 40px`(좌우 패딩 각 20px).
  - 최대 높이 = `Device Height − (상단바 영역 + 10px) − (하단 버튼 영역 + 16px)`.
- **비율 조건부 분기**:
  - **Case A(가로형·정방형)**: 너비가 최대 너비에 먼저 도달 → 배경 컨테이너·테두리 없이 **원본 단독 노출**, 너비 100%(좌우 패딩 20px).
  - **Case B(세로형)**: 높이가 최대 높이에 먼저 도달해 좌우가 남음 → **흰색 컨테이너**(너비 DW−40px, 높이=이미지 높이) 생성, 이미지 **중앙 정렬**, **컨테이너 외곽선에만 Gray-500 1px** 스트로크(이미지 자체엔 테두리 없음).

## 참고 목업
- 세로형(Case B, 흰 컨테이너+중앙+테두리) vs 정방형(Case A, 너비 100% 단독) 비교 목업 1장.
