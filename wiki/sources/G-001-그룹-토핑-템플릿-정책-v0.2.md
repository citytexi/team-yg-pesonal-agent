# 그룹 토핑 템플릿 — 1. Topping-Group (v0.2)

- **원본**: `raw/G-001-그룹-토핑-템플릿-정책-v0.2.md`
- **날짜**: 2026-07-26 (v0.2, DSN-B)
- **도메인**: product

## 핵심 요점
- **특정 토핑 조회 실패 시**: 그룹 칩은 **정상 노출**, 토핑 영역만 **'조회 실패 그래픽' 1종**으로 대체. 형태 = **물음표**(에셋 `Template-E…`).
- **특정 토핑 내 이미지 없음**(해당 그룹에 아직 첫 토핑 없음): **'토핑 템플릿 그래픽'** 노출, **첫 토핑이 등록될 때까지** 유지.
- **템플릿 = 총 6종.** v0.2는 종류를 **이름으로 열거하지 않고 에셋 시트로 대체**("총 6종, 하단 참고").
- **부여 규칙**: 6종 중 **1종 랜덤 최초 부여 → 첫 토핑 등록 전까지 고정**.
- **불변 조건 명시**: 새로고침·재접속·타 그룹 갱신 등 상태 변화가 일어나도 **이미 부여된 그래픽은 바뀌지 않는다.**
- 에셋 시트(`raw/assets/G-001-그룹-토핑-템플릿-v0.2-그래픽시트.png`) 표기 — 전부 회색 계열 반투명 아웃라인:

| 에셋명 | 형태 |
|---|---|
| Template01 | 별 (도트 무늬) |
| Template02 | 별 (격자 무늬) |
| Template03 | 음표 (8분음표) |
| Template04 | 음표 (쌍음표) |
| Template05 | 소용돌이 (가는 선) |
| Template06 | 소용돌이 (굵은 선) |
| Template-E… | 물음표 (조회 실패용) |

- 적용 예시 목업: 템플릿 그래픽도 일반 토핑과 동일하게 지그재그 배치·그룹 칩 노출 규칙을 따른다.

## v0.1 → v0.2 변경
- 개정이력 표기: "빈 캔버스 템플릿 및 **에러 템플릿 이미지 추가**".
- 템플릿 6종 지정 방식: **이름 열거**(딸기·키위·오레오·딸기과자·파랑젤리·노랑젤리) → **에셋 시트 참조**("총 6종, 하단 참고"). 실제 에셋은 별·음표·소용돌이 계열로 **음식 이름과 일치하지 않는다**.
- 조회 실패 그래픽 서술: "물음표 모양 **과자 형태**" → "물음표 모양 형태"(과자 표현 삭제, 에셋도 과자 형태 아님).
- 나머지 조항(그룹 칩 정상 노출·랜덤 1종 고정·상태 변화 불변)은 **동일**.
