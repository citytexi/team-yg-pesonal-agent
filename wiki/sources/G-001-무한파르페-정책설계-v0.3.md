- **상태**: ✅ **현행 정본** — G-001 정책 설계서 최신본. [[G-001-무한파르페-정책설계-v0.2]] 전면 대체.

## v0.2 → v0.3 변경

- **좌표 컨테이너 정의 신설**: 기준은 **파르페 템플릿 전체(가로 324.3)** — 크림도, 화면도 아님.
  Left = 좌측 인셋 **4**(x=4) / Right = 우측 인셋 **4**(x=160.3). **구 인셋 28 폐기.**
  - Left↔Right 가로 관계 **3.7(겹침)**은 템플릿 폭에서 자동 결정되는 **파생값** — 직접 지정하지 않음.
  - **토핑·칩이 크림 폭을 넘는 것은 정상 동작**. 경계는 크림이 아니라 템플릿.
- **저개수 범위 확정**: +12 내림 대상이 **N = 1 / 2 / 3**(v0.2는 N=1/2만 명시해 N=3이 모호했음).
  N ≥ 4는 기준 y 그대로(첫 토핑 268), N ≤ 3은 **280**.
- **Right 열 y 근거 정정**: "인접 두 Left 토핑 **사이 높이**"(구 "가운데 높이") + **실측 기준 Left y + 86**.
  서술과 수치(354/502/650)의 불일치가 원문에서 해소됨.
- **변형 번호 랜덤 재부여 확정**: Left는 `Left-1~3`, Right는 `Right-1~3` 중 **랜덤 부여**.
  정렬이 바뀌면 타입도 바뀐다. **구 "변형 시드는 그룹 ID 고정이라 유지" 서술 폐기.**
  - **재추첨 시점 = 목록 조회 응답 1회.** 리렌더·셀 재사용 시 재추첨 금지(회전각 튐 방지).
- **크림 가로폭 확정**: **고정 이미지 에셋 + 중앙 정렬**, 비율 고정. 화면 폭에 비례해 늘지 않고
  좌우 여백만 늘어남. ❌ 1안(그리드 전체 폭/화면 폭 추종) 폐기.
- **상태 2종 신설**: ① 특정 토핑 **조회 실패** → 토핑 조회 실패 그래픽(그룹 칩은 정상 노출)
  ② 특정 토핑 **이미지 없음**(아직 아무도 토핑을 안 올린 그룹) → 토핑 템플릿 그래픽,
  **Type 6개**(딸기/키위/오레오/딸기과자/파랑젤리/노랑젤리).
- **캐싱 종결**: 프리뷰 이미지만 지연 로딩 + 캐싱. **그룹 목록 자체는 캐싱 안 함(매번 재조회)**.
- **정렬 근거 강화**: 활동순 확정 — **투표 9인 전원 일치, 2026-06 종결**.
- **데이터 모델 표 신설**: 그룹 ID(미노출) / 프리뷰 이미지 / 이름 / 활동 시간(상대시간).
- **접시 하단 갭 표기 변경**: `-16` → **최소 16**(스크롤 발생 시에만 적용).

## 핵심 요점 (v0.2에서 유지)

- 배치: 지그재그(행당 1개 좌/우, `index % 2`), 첫 토핑 Left 고정.
- 같은 side 세로 갭 **-12** → 같은 열 y 간격 +148. Left 268/416/564 · Right 354/502/650.
- 템플릿 고정 갭: 체리 ↔ 첫 토핑 **-65** / 마지막 토핑 ↔ 접시 **-48**.
- 토핑 규격: 프레임 **160×160**, Img **96×96**, 6타입 상수(Left-1 `26/16/6°/-7` … Right-3 `25/16/-8°/-8`),
  Z는 Img > Grouptag-Chip.
- 조회: 단일 API 호출·페이지네이션 없음. 갱신: Pull-to-Refresh 전체 교체·최상단 초기화,
  재진입 시 자동 재조회.
- 그룹 나가기: 뒤 토핑 한 칸씩 당김 → 이후 좌/우·타입·회전 변경은 **정상 동작**. 크림 수축·접시 상승.
  반영은 저장·재진입 시(실시간 아님).
- 라벨: 그룹명 **80px 초과 시 `…`**(문자수 기준 폐기), 시간 텍스트는 전체 노출, 칩 폭은 내용 기준.
- NEW: C-001 진입해야 읽음 처리.
- 크림 개수: 0~3개 → 3개, 4개부터 토핑 1개당 1칸 추가.
- z-index: 접시1 < 크림2 < 체리3 < 토핑/라벨4.

## 해소된 미결 (→ [[open-questions]])

- **N=3 첫 토핑 y** → **280**(저개수 +12 대상이 N=1/2/3).
- **Right 열 y 서술 vs 수치** → 실측 **Left+86**, 서술도 "사이 높이"로 정정.
- **크림 가로 길이 1안/2안** → **고정 이미지 + 중앙 정렬 확정**, 1안 폐기.
