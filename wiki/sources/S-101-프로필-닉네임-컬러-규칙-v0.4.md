# 프로필 이미지 및 토스트 닉네임 텍스트 컬러 규칙 v0.4 (정본)

- **원본**: `raw/S-101-프로필-닉네임-컬러-규칙-v0.4.md`
- **날짜**: 2026-08-17 (작성자 DSN-B)
- **도메인**: product
- **적용 범위**: 1. Nametag-Chip / 2. Toast > Username (원문 표지 기재). 단 예시 이미지에는 Grouptag-Chip의 Default 표기도 포함돼 선언 범위를 넘는다 → [[open-questions]]
- **비고**: v0.3([[S-101-프로필-닉네임-컬러-규칙-v0.3]])을 **전면 대체**하는 정본. 1~3장(12종 구성·타입 고정·토스트 컬러 매핑)은 v0.3 조항을 문구 그대로 재수록하고, **4장 Nametag-Chip Default 상태**만 신설했다. Grouptag-Chip Timestamp 매핑은 v0.3과 마찬가지로 이 규칙 범위 밖이며 별도 문서([[S-101-프로필-이미지-및-그룹칩-내-타임스탬프-컬러-규칙-v0.1]]) 소관이다.

## 핵심 요점
- **프로필 이미지**: 닉네임 첫 글자 원형 이미지(Nametag-Chip). 6컬러 × 2타입 = 12종, 계정당 1종 랜덤. (v0.3 동일)
- **타입 고정**: 계정 생성 시 1회 랜덤·불변, 동일 닉네임·다른 계정 → 다른 타입 가능, 모든 화면·재접속·그룹 변경에도 유지. (v0.3 동일)
- **컬러 매핑**(토스트 닉네임 텍스트, 타입별 강제):
  연핑크(1,2)→Cherry-200 / 진핑크(3,4)→Cherry-300 / 체리(5,6)→Cherry-400 / 그레이(7,8)→White / 멜론(9,10)→Melon / 푸딩(11,12)→Pudding. (v0.3 동일)
- **Default 상태 (v0.4 신규)**: Nametag-Chip을 정상 결정할 수 없는 모든 상황에 Default를 노출한다. 원문이 든 예시는 **탈퇴한 그룹원**과 **불러오기 실패** 2건이고, 원문 문장은 "Nametag-Chip에 문제 생기면 다 Default로 노출"이라 **열거가 아니라 포괄 규칙**이다.
- **Default 표현**(예시 이미지에서만 확인): 칩은 첫 글자 대신 **`-`(대시) 글리프**, Toast는 `{닉네임}님이` 대신 **`알 수 없는 사용자가`**, Grouptag-Chip은 닉네임 자리에 **`알수없음`**. 이미지 주석 "탈퇴했으면 무조건 이름 알수없음임".
- 개인정보: 작성자·예시 실명 마스킹(더미 `홍씨` 닉네임 두 계정). 원본 스크린샷은 예시 영역에 실명이 찍혀 있어 `raw/assets/`에 미보관.

## v0.3 대비 변경
- **4. Nametag-Chip Default 상태 추가** — 12종 타입 중 하나를 결정할 수 없을 때의 폴백이 규칙으로 들어왔다. v0.3까지는 "12종 중 1종이 반드시 배정된다"만 있어 배정값을 못 읽는 경우의 표현이 공백이었다.
- 그 외 조항 변경 없음. 컬러 매핑 6행, 타입 고정 정책, 12종 구성 모두 v0.3과 동일.

## 기존 규칙과의 관계 (모순 아님)
- **C-202와 일치·확장**: [[C-202-토핑-편집자-확인-규칙-v0.1]]이 이미 탈퇴 유저 Toast를 `알 수 없는 사용자가 59분 전에 쌓았어요`로 규정했다. v0.4는 같은 문구를 재확인하면서, 문구뿐이던 규칙을 **칩 그래픽 자체**로 확장했다.
- **기능정의서 계열과 일치**: [[기능정의서-v6]] C-202 행 비고 "탈퇴 유저는 '알 수 없음' 표기"와 같은 취지.

## 미해결 (→ [[open-questions]])
- ⚠️ **Default의 컬러 토큰 미명시** — §3 매핑표에 Default 행이 없고, 칩 배경·테두리·토스트 닉네임 텍스트의 토큰 이름이 원문에 없다. 예시 이미지상 회색 계열로만 확인된다.
- ⚠️ **Grouptag-Chip Default의 관할 공백** — 예시 이미지가 Grouptag-Chip `알수없음`을 함께 보여주나, Grouptag-Chip은 v0.3에서 분리돼 이 규칙 범위 밖이고 관할 문서([[S-101-프로필-이미지-및-그룹칩-내-타임스탬프-컬러-규칙-v0.1]])에는 Default 조항이 없다. 표기도 `알 수 없는 사용자`(Toast)와 `알수없음`(Grouptag-Chip)으로 갈린다.
