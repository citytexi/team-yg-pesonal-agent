## 핵심 요점
- [[협업-캔버스-앱]] 6차 기능정의. [[기능정의서-v5]] 대비 **화면 구조 변경은 G-002 제거 1건**, 나머지 화면 정의는 동일.
- 페이지 비고: **에딧 모드 삭제**.
- v6 Notion 원본의 담당자(인물)·진행상황(iOS/안드 작업 중·디자인 작업/검수) 컬럼은 **가변 항목이라 raw에 미포함**(실명 마스킹 불필요).

## v5 → v6 변경
- **G-002(그룹 진입) 삭제**: v4·v5에서 캡처 미포착이던 [[open-questions|G-002]]가 v6 표에 아예 없음 → 관련 흐름 C-001 직접 진입으로 재배선.
  - A-004(그룹 참여)·A-005(새 그룹 생성) 다음 단계: `G-002` → **`C-001`**.
  - C-001(메인 캔버스) 진입 경로: `G-002` → **공백**(직접 진입).
  - G-001(그룹 목록) 다음 단계: `S-001, G-002, A-003` → **`S-001, A-003, C-001`**.
- **담당 컬럼 개편**: v5의 역할 코드 4컬럼(디자인/iOS/AOS/Spring) → v6는 담당자(인물)+진행상황 2컬럼. raw엔 미반영.

## 미해결 (→ open-questions)
- **"에딧 모드 삭제" 비고 vs C-301~C-306 잔존**: 페이지 비고는 에딧 모드 삭제라 하나 파르페 편집 모드 진입(C-301)·하위 편집 화면(C-302~C-306)은 v6 표에 그대로 존재. "에딧 모드" 대상 원본 확인 필요.
- **G-002 삭제 후 그룹 권한 검증 위치**: 기존 G-002가 담당하던 "그룹 권한 유효 검증·강퇴/탈퇴 접근 차단"이 어느 화면으로 흡수됐는지 v6 표 미명시.
- **A-003 흐름 불일치(v5 잔존)**: A-004/A-005가 여전히 진입경로로 A-003(약관 동의) 참조.
- **SY-002 참조**: C-001 분기조건 "없으면 SY-002로 자동 생성"이나 SY-002 행 없음(SY-001-new가 실제 담당). v5부터 이어진 표기 불일치.
