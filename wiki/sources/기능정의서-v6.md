## v5 → v6 변경
- **G-002(그룹 진입) 삭제**: v4·v5에서 캡처 미포착이던 [[open-questions|G-002]]가 v6 표에 아예 없음 → 관련 흐름 C-001 직접 진입으로 재배선.
  - A-004(그룹 참여)·A-005(새 그룹 생성) 다음 단계: `G-002` → **`C-001`**.
  - C-001(메인 캔버스) 진입 경로: `G-002` → **공백**(직접 진입).
  - G-001(그룹 목록) 다음 단계: `S-001, G-002, A-003` → **`S-001, A-003, C-001`**.
- **담당 컬럼 개편**: v5의 역할 코드 4컬럼(디자인/iOS/AOS/Spring) → v6는 담당자(인물)+진행상황 2컬럼. raw엔 미반영.

## 미해결 (→ open-questions)
- ~~**"에딧 모드 삭제" 비고 vs C-301~C-306 잔존**~~ → **해소**: [[기능정의서-v7]]에서 **C-301 실제 삭제**. 편집 모드 진입은 C-304가 배경·토핑 탭으로 흡수했다. 즉 표 갱신 누락이었다.
- ~~**G-002 삭제 후 그룹 권한 검증 위치**~~ → **해소**: [[기능정의서-v7]]에서 **G-002 복원**. "그룹 권한 유효 여부" 분기가 원위치했다.
- ~~**A-003 흐름 불일치(v5 잔존)**~~ → **해소**: [[기능정의서-v7]]에서 A-004·A-005 진입 경로가 **G-001**로 바뀌었다.
- **SY-002 참조**: C-001 분기조건 "없으면 SY-002로 자동 생성"이나 SY-002 행 없음(SY-001-new가 실제 담당). v5부터 이어진 표기 불일치.
