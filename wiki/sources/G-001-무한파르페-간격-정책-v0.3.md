## 핵심 요점

### 배치 패턴 (v0.2 유지)
- 토핑 **행당 1개**, 좌/우 번갈아. 위→아래 좌 → 우 → 좌 → 우 무한 반복. 첫 토핑 Left/Right **고정 시작(브래킷 미확정)**. 인덱스 0부터 `index % 2 == 0`→Left, `==1`→Right.
- 크림은 토핑 총량만큼 세로 확장, 체리(최상단)·접시(최하단)는 고정 요소.
- **정렬 = 최근 활동순**, **동률(밀리초까지 동일) 시 그룹 생성일시 최신순** ← v0.3 신규 타이브레이크.

### 좌표 (v0.3 신설 — 개정 핵심)
- **측정 기준**: 모든 간격은 토핑 프레임 **160×160** 기준. 회전·이동으로 프레임 밖 삐져나간 픽셀은 측정 대상 아님.
- **기준 x (고정)**: Left = 전체 템플릿 기준 **좌측 인셋 4** / Right = **우측 인셋 4**.
- **첫 토핑(Left, index 0)**: y = **280**(저개수 특수 배치). **N ≥ 4에서는 첫 토핑 y = 268**.
- **같은 side 세로 갭 = -12** (프레임 160 기준 → 같은 열 y 간격 **+148**).
- **Left 열**: y = 268, 416, 564, …
- **Right 열**: y = 354, 502, 650, … (원문 규칙: "인접한 두 Left 토핑의 가운데 높이")
- 변형 번호(1/2/3)는 세로 갭에 영향 없음 — 같은 side면 -12 동일.

### 템플릿 고정 갭 (v0.3 신설)

| 구간 | 갭 |
|---|---|
| 체리 ↔ 첫 토핑 | -65px |
| 마지막 토핑 ↔ 접시 | -48px |
| 접시 ↔ 스크롤 인디케이터 | 최소 -16 (스크롤 발생 시에만) |

### 저개수 특수 배치 (v0.3에서 좌표화)
- **N = 0** → 토핑 없음. 크림 최소 + 접시. 안내는 온보딩 툴팁(**G-001-Empty**) 담당. 구 "크림 상단 42% 지점 빈 상태 안내 문구" **폐기** 명시.
- **N = 1 / N = 2** → 여백 고려, N ≥ 3 배치 대비 각 토핑 y **+12 내림**(아래로). x는 동일.
- **N = 3** → 스크롤 없음, 파르페 세로 성장 없음.
- **N = 4 이상** → 스크롤 + 크림 추가(세로 성장) 시작.

### 토핑 규격·타입별 상수 (v0.2와 동일, 변경 없음)
- 토핑 = Img + Grouptag-Chip, **6타입**. 프레임 160×160, Img 96×96(정중앙), Chip 회전 없음, Z는 **Img > Chip** 항상. Chip 기준점 = **[프레임 중앙 하단 / Img 중앙 하단]**(브래킷 미확정). 그룹명 80px 초과 시 `...`. Timestamp 컬러 = [[nametag-chip]] 규칙 준수(랜덤 X).

| 타입 | Img Translate X | Y | Img Rotate | Chip Offset |
|---|---|---|---|---|
| Left-1  | 26 | 16 | 6°   | -7 |
| Left-2  | 24 | 11 | 12°  | -5 |
| Left-3  | 25 | 16 | -8°  | -8 |
| Right-1 | 26 | 16 | -6°  | -6 |
| Right-2 | 22 | 8  | -16° | -3 |
| Right-3 | 25 | 16 | -8°  | -8 |

### 그룹 수 변동 재계산 (v0.2와 동일)
- 그룹 나가기 → 토핑 제거, 빈자리 없이 뒤 토핑이 정렬 순서대로 한 칸씩 위로 당겨짐. 크림 수축·접시 상승. 반영 시점 = 저장·화면 재진입 시(실시간 아님).

## v0.2 대비 변경
- **신설**: 2.2 좌표 및 배치(좌/우 인셋 4·첫 토핑 y·같은 side 갭 -12·Left/Right y열), 2.3 템플릿 고정 갭(체리 -65·접시 -48·인디케이터 최소 -16), 2.4 저개수 특수 배치 수치화.
- **신설**: 정렬 동률 타이브레이크(그룹 생성일시 최신순).
- **명시적 폐기**: 구 "크림 상단 42% 지점 빈 상태 안내 문구" → 온보딩 툴팁 G-001-Empty로 일원화.
- **동일 유지**: 지그재그 패턴·`index%2`·프레임 160/Img 96·6타입 상수 표·그룹 수 변동 재계산.

## ⚠️ 원본 내 불일치 (→ [[open-questions]])
- **Right 열 y가 "인접 두 Left 가운데"와 불일치**: Left 268/416의 중간은 342인데 표기값은 **354**(Left+86). 502·650도 동일하게 Left+86. 서술 규칙(중간값)과 수치가 어긋남.
- **N = 3의 첫 토핑 y 불명**: 2.2는 "4개 이상부터 268" → N=3도 280 함의. 2.4는 +12 내림을 **N=1/2에만** 명시. N=3이 268인지 280인지 미확정.
- (v0.2에서 이월) 미확정 브래킷 2건: 1.1 시작 사이드 `[Left / Right]`, 3장 Chip 기준점 `[프레임 중앙 하단 / Img 중앙 하단]`.
