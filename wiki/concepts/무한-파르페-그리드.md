# 무한 파르페 그리드

[[협업-캔버스-앱]]의 그룹 목록 메인 화면(G-001) 레이아웃. 그룹 하나가 파르페 위 **[[토핑]]** 한 개로 표현되고, 그룹이 늘수록 파르페가 아래로 무한히 길어진다. 디저트(파르페) 메타포를 화면 전체에 확장한 것.

## 배치 패턴 (v0.3 현행 — 지그재그, [[G-001-무한파르페-간격-정책-v0.3]])
- 토핑 **행당 1개**, 좌/우를 번갈아(지그재그) 배치. 위→아래 좌 → 우 → 좌 → 우 무한 반복. 첫 토핑은 Left/Right 고정 시작.
- **인덱스 규칙** (0부터, 2개 단위 반복):

| index % 2 | 사이드 |
|---|---|
| 0 | Left |
| 1 | Right |

- **저개수**: `N=0` → 토핑 없음(안내는 온보딩 툴팁 G-001-Empty 담당, 0건 상시 노출). `N=1/2/3` → 스크롤 없음. N≥4 배치 대비 각 토핑 **y +12 내림**(x 동일), 파르페 세로 성장 없음. **N=4부터** 스크롤 발생·기준 y 그대로·크림 개수 증가. (v0.3 확정)
- 레이아웃: 체리 자리(최상단, 고정) → 토핑 지그재그 → 파르페 접시 자리(최하단, 고정). 크림은 토핑 총량만큼 세로로 늘어남.
- 각 [[토핑]]은 6타입(`Left-1/2/3`·`Right-1/2/3`)의 Translate·Rotate·Chip Offset 고정 상수로 살짝 기울여 얹는다. 상세 규격 → [[G-001-무한파르페-간격-정책-v0.3]] / [[토핑]].

## 좌표 (v0.3 현행, [[G-001-무한파르페-간격-정책-v0.3]] · [[G-001-무한파르페-정책설계-v0.3]])
배치 모델은 v0.2 그대로고 좌표만 수치로 확정됐다. 인셋 정책 변경(28 → 4)과 좌표 컨테이너 정의가 v0.3의 요지.

- **좌표 컨테이너 = 파르페 템플릿 전체**(체리~접시 포함 고정 이미지 영역, 가로 **324.3**). 크림도 화면도 아니다 — **토핑·칩이 크림 폭을 넘는 것은 정상 동작**이고, 템플릿 밖으로는 나가지 않는다. (v0.3 확정)
- **기준 x (고정)**: Left = **좌측 인셋 4**(x=4) / Right = **우측 인셋 4**(x=160.3). Left↔Right 가로 관계 **3.7(겹침)**은 템플릿 폭에서 결정되는 **파생값** — 직접 지정하지 않음.
- **같은 side 세로 갭 = -12** (프레임 160 기준 → 같은 열 y 간격 **+148**). 변형 번호(1/2/3)는 갭에 영향 없음.
- **Left 열**: y = 268, 416, 564, … / **Right 열**: y = 354, 502, 650, …
- 첫 토핑(Left, index 0): **N ≥ 4 → y = 268**(스크롤 발생 기준), **저개수 N = 1/2/3 → y = 280**(+12 내림). ✅ v0.3에서 N=3 포함으로 확정.
- **Right 열 y**: 인접한 두 Left 토핑 **사이 높이**, **실측 기준 Left y + 86**. ✅ v0.3에서 서술·수치 정합(구 "가운데 높이"=342 해석 폐기).
- **템플릿 고정 갭**: 체리 ↔ 첫 토핑 **-65px** / 마지막 토핑 ↔ 접시 **-48px** / 접시 ↔ 스크롤 인디케이터 **최소 -16**(스크롤 발생 시에만).

> 🔁 **구 모델(대체됨)**: v0.1/[[G-001-무한파르페-정책설계]]의 `2-1-2-1` 스태거(index%3, 2열/1열)·프레임 180·3타입(1/2-Left/2-Right)은 v0.2 지그재그로 대체됨. 아래는 이력.

## 측정 기준 (v0.2~v0.3)
- 모든 간격은 **토핑 프레임 160×160** 기준. Img 회전·이동으로 프레임 밖으로 삐져나가는 픽셀은 측정 대상 아님.
- 세부 갭은 개별 수치 표 대신 타입별 Translate/Rotate/Chip Offset 상수로 표현 → [[토핑]] 규격 표.

<details><summary>구 갭 표 (v0.1, 대체됨 — 180 프레임·2-1-2-1)</summary>

| 구간 | 방향 | 갭 |
|---|---|---|
| 체리 ↔ 첫 Type 1 | 세로 | 12px |
| Type 1 ↔ Type 2-Left | 세로 | 12px |
| Type 1 ↔ Type 2-Right | 세로 | 24px |
| Type 2-Left ↔ Type 2-Right | 가로 | 0px |
| Type 2-Right ↔ Type 1 | 세로 | 12px |

- 끝 처리: 마지막 2-Left ↔ 접시 세로 12px, 마지막 2-Right ↔ 접시 세로 0px.

## 파르페 요소 (z-index)
아래→위 순서로 쌓임.

| 요소 | z-index | 역할 |
|---|---|---|
| 접시 | 1 | 기능 없음(장식) |
| 크림 | 2 | 배경 패딩. **개수**: 토핑 0~3개 → 크림 3개, 4개부터 토핑 1개당 크림 1칸 추가. **가로폭 = 고정 이미지 에셋 + 중앙 정렬**(비율 고정, 화면 폭에 비례해 늘지 않고 좌우 여백만 늘어남) ✅ v0.3 확정 — 구 1안(그리드 전체/화면 폭 추종) 폐기 |
| 체리 | 3 | 차후 기능(MVP 이후), TBD → [[open-questions]] |
| [[토핑]] / 라벨 | 4 | 그룹 대표 프리뷰 + 이름·시간 칩 |

## 조회·정렬 (v0.3 현행)
- 단일 API 호출로 전체 조회(페이지네이션 없음). 필드 = 그룹ID·프리뷰이미지·이름·활동시간.
- 정렬 = **활동순 확정**(자주 보는 그룹 상단). **동률(밀리초까지 동일) 시 그룹 생성일시 최신순**(v0.3 신규 타이브레이크). 프리뷰 이미지 지연 로딩 + 캐싱.
- 정렬 근거: **투표 9인 전원 일치, 2026-06 종결**(v0.3 명시).
- 상태별: 초기 로딩 = **자체 로딩 그래픽**(인디케이터·스켈레톤 대신 제작) / 성공 / 0건 = 온보딩 툴팁(G-001-Empty) / 실패 = Error + 새로고침.
  - **특정 토핑 조회 실패** → 토핑 조회 실패 그래픽(그룹 칩은 정상 노출). (v0.3 신설)
  - **특정 토핑 이미지 없음**(아직 아무도 토핑을 안 올린 그룹) → 토핑 **템플릿 그래픽**, Type 6개(딸기/키위/오레오/딸기과자/파랑젤리/노랑젤리). (v0.3 신설)
- 갱신: Pull-to-Refresh 전체 교체·스크롤 최상단 초기화. 재진입 시 **자동 재조회 확정**.
- 캐싱: 프리뷰 이미지만 지연 로딩 + 캐싱. **그룹 목록 자체는 캐싱 안 함(매번 재조회) — 종결**(v0.3).
- 데이터 모델: 그룹 ID(조회하되 **미노출**) / 프리뷰 이미지 / 이름 / 활동 시간(상대시간).

## 라벨 정책
- 이름 칩: 한 줄 고정, 토핑 우측 하단. 폭은 내용 기준(토핑 폭 비종속). Timestamp 텍스트 컬러 = [[S-101-프로필-닉네임-컬러-규칙-v0.3]] 준수(랜덤 X).
  - 이름 **80px 초과 시 초과분부터 `…`**(픽셀 기준, v0.2). 구 "6자/7자+ → 앞 5자 + `…`" 문자수 기준은 **폐기**.
- **상대 시간**(대표 토핑 마지막 활동 시각 기준, 항상 전체 노출):

| 경과 | 표기 |
|---|---|
| 60초 미만 | 방금 전 |
| 1~59분 | N분 전 |
| 1~23시간 | N시간 전 |
| 1~6일 | N일 전 |
| 7일 이상 | 오래 전 |

- **NEW 기준**: C-001 진입해야 읽음 처리(화면 노출만으로 해제 안 됨). (v0.1의 `lastActivityAt` 24h 폴백은 그룹 캐싱 전제 규칙 → 그룹 캐싱 미채택으로 v0.2에서 삭제됨.)

## 상호작용
- 대표 토핑 클릭 → 개별 토핑을 잡고 있는 **C-001**(그룹 캔버스 메인)로 이동.
- 그룹 나가기 → 해당 토핑 제거, 뒤 토핑이 정렬 순서대로 한 칸씩 당겨짐. side=`index%2`라 **당김 지점 이후 모든 토핑의 좌/우·타입·회전이 바뀜 = 정상 동작**. 크림 수축·접시 상승. 저장·재진입 시 반영(실시간 아님).
- **변형 번호(1/2/3) = 랜덤 재부여**(v0.3 확정, [[G-001-무한파르페-정책설계-v0.3]]). Left 토핑은 `Left-1~3`, Right는 `Right-1~3` 중 랜덤. 활동 최신순 정렬이라 새로고침으로 순서가 바뀌면 타입도 바뀐다.
  - **재추첨 시점 = 목록 조회 응답 1회.** 리렌더·셀 재사용 시 재추첨 금지(회전각 튐 방지).
  - 🔁 구 서술 "변형 시드는 그룹ID 고정이라 유지"는 **v0.3에서 명시 폐기**.
