# 캘린더 컴포넌트 (C-201)

[[협업-캔버스-앱]]에서 날짜를 선택·이동할 때(C-201) 노출되는 캘린더의 컴포넌트 정의. 일자 버튼(Button-Date) + 토핑 업로드 표시(Chip-Indicator)를 합친 셀(List-Date)로 구성.

## Button-Date (일자 버튼) — 4상태
| 상태 | 정의 |
|---|---|
| Default | Selected·Today·Disabled가 아닌 모든 경우 |
| Selected | 사용자가 선택한 날짜 |
| Today | 오늘 날짜 |
| Disabled | 캔버스를 볼 수 없는 **미래의 날짜** |

- **우선순위**: Selected와 Today가 겹치면 **Selected로 노출**.

## Chip-Indicator (토핑 인디케이터)
- **Upload/True**: 해당 날짜 업로드 [[토핑]] **1개 이상**.
- **Upload/False**: 해당 날짜 토핑 **0개**.

## List-Date (캘린더 셀)
- **Button-Date + Chip-Indicator** 조합. True/False 판정 기준은 Chip-Indicator와 동일.
- **예외**: Button-Date가 **Disabled**면 Chip-Indicator는 **항상 False**.
- 시각 케이스: Default/선택/오늘 × 토핑 O/X, 그리고 미래 날짜(Disabled → 토핑 X 고정).

## 열기·닫기 (v7 신설, [[기능정의서-v7]])
- **열기**: 날짜바 좌측 **캘린더 아이콘 + 날짜 라벨** 탭 → 딤드(반투명 오버레이)와 함께 오픈.
- **오픈 시 연/월**: **항상 지금 보고 있는 캔버스 날짜가 속한 연월**이다. 예외가 없고, 직전 탐색 상태와 무관하게 열 때마다 재적용된다.
- **닫기 트리거 2종**: 캘린더 아이콘 재탭(토글) / 딤드 영역 탭. 둘 다 동일하게 "그냥 닫힘"이고, 일자를 고르지 않고 닫으면 **캔버스는 이동하지 않는다**.
- **탐색 상태는 폐기된다**: 연·월만 바꾸고 일자를 고르지 않은 채 닫으면 연/월 탐색 상태를 **discard**하고 세션 내에 유지하지 않는다. 다시 열면 무조건 현재 캔버스 날짜의 연월부터 시작한다.
- **2단 닫기**: 월·연도 리스트가 열린 상태에서 딤드를 탭하면 **리스트만 닫히고 날짜 그리드로 복귀**하며 캘린더 자체는 열려 있다. 완전히 닫으려면 리스트를 먼저 닫은 뒤 딤드를 한 번 더 탭하거나 아이콘을 재탭해야 한다.

## 연·월 리스트 (v7 신설)
- **동시에 열리지 않는다** — 한쪽을 열면 다른 한쪽(또는 날짜 그리드)이 닫힌다.

### 노출 범위
| 리스트 | 하한 | 상한 | 정렬 |
|---|---|---|---|
| 연도 | **배포연도(2026) 미만 미노출** — 업로드가 불가능했던 기간 | 오늘 기준 **현재연도 초과 미노출** | 오름차순(과거→현재) |
| 월 | 선택 연도가 배포연도면 **배포월(9월) 미만 미노출**, 그보다 큰 연도면 1월부터 | 선택 연도가 현재연도면 **현재월 초과 미노출**, 과거 연도면 12월까지 | 오름차순(1월→12월) |

- **업로드 0건인 연도·월 항목**은 노출 범위 안이어도 **노출하되 Disabled** 처리한다. 숨기지 않는다.

### 스크롤
- 항목 **1~5개**: 풀 노출. 항목이 늘 때마다 컨테이너 높이가 아래로 늘어나고 **내부 스크롤이 없다**.
- 항목 **6개 이상**: `max-height 220px` 고정 + 내부 스크롤. 산식은 **항목 버튼 높이 44px × 5행 = 220px**.

### 선택 즉시 반영
- 연/월 항목을 탭하면 **확인·이동 버튼 없이 즉시** 그 값으로 날짜 그리드가 갱신되고 그리드 화면으로 자동 복귀한다.
- **이 시점에는 캔버스가 이동하지 않는다.** 그리드만 재렌더링되고 Today/Selected/Disabled/Chip-Indicator가 새 연/월 기준으로 재계산된다.
- 연·월 선택은 각각 독립적으로 즉시 적용되고, **최종적으로 일자를 탭해야 캔버스 이동이 일어난다.** 연/월을 옮겨 둔 상태에서 일자를 탭하면 그 연/월+일이 확정값이 된다.
- 날짜 그리드에서 Button-Date(Disabled 제외)를 탭하면 **즉시 해당 날짜 캔버스로 이동**하고 캘린더·드롭다운이 자동으로 닫힌다.

> 연/월 선택은 **즉시·비이동**, 일자 선택은 **즉시·이동**이다. 같은 "즉시 적용"이라도 캔버스 이동 여부가 갈린다.
