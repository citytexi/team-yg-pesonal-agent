# 누끼 편집 (C-104)

[[협업-캔버스-앱]]에서 자동 누끼 결과를 사용자가 **수동으로 보정하는 편집 화면(C-104)**의 렌더링·제스처·편집 가이드 규칙. 편집 대상은 [[누끼-따기|누끼 캔버스]](객체+여백, C-103-Selected 생성)다. 원본 [[C-104-누끼-편집-정책-v0.1]](2026-07-09).

## 뷰포트 · 초기 렌더링
- **기준 영역**: 상단 Button-Container 하단 ~ 하단 Edit-Area 상단 사이 전체 공간.
- **초기 스케일링**: 원본 비율 유지 **Aspect Fit**(잘리지 않고 꽉 차게).
- **최소 여백**: 상/하단 UI ↔ 이미지 사이 **최소 10px**.
- **정렬**: 뷰포트 내 **세로 중앙 + 가로 중앙**.

## 제스처 · 확대 뷰포트
- **확대(Zoom-in)**: 2핑거 제스처 허용.
- **축소 차단**: 초기 렌더링 크기(**Scale 1.0**) 미만 축소 원천 차단.
- **Pan 제한**: 확대 후 이미지가 뷰포트 밖으로 완전 이탈하지 않도록 **한계선 Clamping**.
- **확대 시 작업 공간**: 초기 렌더링 너비와 무관하게, 확대 상태에선 좌우 패딩 20px 제외한 **`Device Width − 40px`** 전체를 브러시 작업 공간으로 활용.

## 시각적 편집 가이드 (Background Opacity)
- **배경 가이드**: '영역 채우기'를 돕기 위해 지워진 원본 배경 픽셀을 **불투명도 50%**로 노출.
- **복구 피드백**: '영역 채우기' 브러시가 지난 영역만 마스킹 해제 → **불투명도 100%로 선명 복구**.

## 브러시 / 테두리 크기
- **브러시 크기**: 최소 **2px** ~ 최대 **50px**.
- **테두리 크기**: 최소 **2px** ~ 최대 **50px**. (테두리 두께·색깔 편집은 C-105 [[기능정의서-v6]]와 연결.)
