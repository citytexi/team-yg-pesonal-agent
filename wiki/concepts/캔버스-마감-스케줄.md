# 캔버스 마감 스케줄

[[협업-캔버스-앱]]은 그룹마다 **하루 1장**의 캔버스를 쓴다. 자정/새벽에 오늘자 캔버스를 마감하고 새 캔버스를 자동 생성하는 시스템 배치(SY-*).

## 동작
- **마감 + 갤러리 저장** (SY-001 / v7 `SY-001-Closed`): 오늘자 캔버스 마감 → 완료 캔버스 이미지 추출 → 그룹 보존 + 사용자 갤러리 저장 옵션. 완료된 캔버스만 추출 가능.
- **신규 캔버스 자동 생성** (SY-003 / v7 `SY-001-New`): 그룹별 오늘자 빈 캔버스 생성. **16:9 비율**. 첫 진입자 빈 상태 트리거 시 fallback 생성.

## 저장 버튼 노출 조건 (v7 변경)
- **구 정책 폐기**: 「저장 버튼은 **마감 시에만** 노출」. [[기능정의서-v7]]이 `SY-001-Closed`·`C-001` 양쪽에서 명시적으로 폐기했다.
- **현행**: 저장 아이콘은 **Empty 상태에서만 미노출**이고, 그 외에는 **마감 여부와 무관하게 항상 노출**된다.
- 즉 **마감이 저장의 전제 조건이 아니게 됐다.** 오늘 캔버스도 작업 도중에 저장할 수 있고, 저장 플로우는 마감 전후가 같은 화면을 쓴다 → [[캔버스-저장-미리보기]].
- 마감 자체의 의미는 남는다 — 마감된 캔버스는 더 이상 편집되지 않고 보존 대상이 된다.

## 실행 시각 변경
- [[기능정의서-v2]]·[[기능정의서-v3]]: 매일 **00:00**.
- [[기능정의서-v4]]부터 매일 **03:00 (KST)** 로 변경. 서버 기준 KST 고정.
- 연동: [[기능정의서-v4]] C-102 갤러리 로드 범위도 "당일 03시~익일 03시"로 하루 경계를 03시에 맞춤.

## 다른 스케줄과의 구분
03시 마감·생성 외에 [[기능정의서-v7]]에서 **푸시 리마인드 스케줄 2종**(10:00 / 20:00 KST)이 신설됐다. 같은 스케줄러 계열이지만 캔버스 생명주기와 무관한 별개 배치다 → [[푸시-알림-정책]].

## 미결
- 마감 시점에 작업 중인(미확정) 객체 처리 정책 미정 ([[open-questions]]). v7 `SY-001-Closed` 분기조건도 "캔버스 완료 여부"까지만 적고 처리 방식은 비워 뒀다.
- 과거 캔버스 조회 가능 기간(예: 30일) 미정. 다만 [[캘린더-컴포넌트]]가 v7에서 **연도 하한을 배포연도(2026)·배포월(9월)로** 고정해 조회 범위의 하한만은 정해졌다.
