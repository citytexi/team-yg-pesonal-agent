# 화면 ID 체계

[[협업-캔버스-앱]] 기능정의서의 화면 식별 규칙. 접두사로 도메인 구분.

| 접두사 | 도메인 | 예 |
|---|---|---|
| `A-` | Auth (인증/온보딩) | A-001 스플래시([[스플래시-애니메이션]]), A-002 로그인 |
| `G-` | Group (그룹) | G-001 그룹 목록 (G-002 그룹 진입은 [[기능정의서-v6]]에서 삭제) |
| `C-` | Canvas (캔버스/편집) | C-001 메인, C-101 촬영, C-301 파르페 편집 |
| `S-` | Sidebar (사이드 메뉴) | S-001 앱 메뉴, S-101 그룹 메뉴 |
| `SY-` | System (스케줄/자동) | SY-001 마감, SY-003 신규 생성 |

## 서브 ID (v5~)
[[기능정의서-v5]]에서 확인/에러/로딩 화면에 하이픈 서브 ID 도입:
- `C-101-confirm`, `C-101-error`, `C-102-confirm`, `C-102-error`
- `C-103-loading`, `C-103-select`
- `SY-001-closed`, `SY-001-new`

## 화면 ID 밖 — 공용 정책 문서

화면 비종속 공용 규칙을 다루는 정책 문서는 이 접두사 체계에 들어가지 않는다. 선례가 둘이고 명명이 서로 다르다.

- [[common-공통-로딩-정책-v0.1]] — 접두사 `common-`. 앱 전역 로딩 애니메이션([[공통-로딩]]).
- [[C-103-이미지-렌더링-정책-v0.1]] — 이름에 `C-103`이 붙어 있으나 **내용은 화면 비종속**이다([[이미지-렌더링-정책]]). 최초 정의 화면이 C-103이었을 뿐이므로, 파일명을 화면 귀속으로 읽으면 안 된다.
