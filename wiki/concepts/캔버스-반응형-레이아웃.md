# 캔버스 반응형 레이아웃 (C-001)

[[협업-캔버스-앱]]의 그룹 캔버스 메인 화면(C-001) 렌더링 규칙. 화면 크기가 달라져도 캔버스 비율·여백을 일관되게 유지하는 반응형 정책. **세로 모드 전용**(태블릿·가로모드 미고려). **현행 [[C-001-캔버스-정책-v0.2]]**(2026-07-22) 기준, v0.1 대비 Canvas 구성 모델·16:9 대상·배경 처리가 바뀜.

> ⚠️ [2026-09-21] **후속 판본 v0.3이 존재하나 `raw/`에 원본이 없다.** [[기능정의서-v7]] `C-001` 행의 `기타` 컬럼에 "C-001 캔버스 정책 v0.3 / 2026-09-18"의 본문이 통째로 전재돼 있을 뿐이다. 본 페이지는 **정책서 원본이 있는 v0.2를 현행으로 유지**하고, v0.3이 전하는 변경은 아래 [v0.3 전언 (원본 미수집)](#v03-전언-원본-미수집) 절에 상충으로만 기록한다. 원본 수집 시 현행화한다 → [[open-questions]]

## Canvas 구성 (v0.2)
- **`Canvas = Canvas-Area + Canvas-Menu`** — 둘이 하나의 Canvas로 묶임.
- **Bottom-Bar**: Canvas-Area 하단에 **gap 없이** 붙어 Canvas의 일부로 이어짐. 화면 하단에 **별도 탭바 없음**(Bottom-Bar가 Canvas 최하단 요소). 고정 높이이며 **16:9 비율 계산에서 제외**.
- (v0.1은 탑바·탭바를 각각 화면 상/하단 플로팅 버튼으로 고정했으나, v0.2에서 하단은 Bottom-Bar로 Canvas에 편입.)

## 좌상단 컷 도형 + 날짜 라벨 (v0.2)
- 캔버스 좌상단 모서리는 직각이 아니라 **비스듬히 잘린 컷 도형**(장식).
- 날짜 라벨(**Button-Date-Select**, 참고 [[캘린더-컴포넌트]])은 컷 위에 표시, **반투명 뒷영역까지 캔버스 영역에 포함**. 위치는 캔버스 카드 상단 고정.
- 라벨 **높이 고정**(스케일 X), **너비는 캔버스 크기 따라 변화**(내부 좌우 패딩은 고정값).
- **저장(내보내기) 시 컷 도형·날짜 라벨 미반영 → 캔버스는 완전한 사각형으로 저장**.

## 캔버스 크기·위치 우선순위 (v0.2)
1. **Canvas-Area만 16:9 비율 유지** (Canvas-Menu는 계산 제외, 고정 높이 별도 추가). ← v0.1은 캔버스 전체 16:9.
2. **Top Bar ↔ Canvas**, **Canvas ↔ 화면 최하단(홈 인디케이터)** 각각 **최소 gap 12px** 보장.
3. 좌우 패딩 **20px** 유지 (가능한 한도 내).

## 배치
- 상단 고정 요소 하단 ~ 화면 최하단 사이 **Canvas 세로 중앙 정렬**, 상단·하단 갭 항상 동일(최소 12px).
- **`Canvas 전체 높이 = Canvas-Area(16:9 계산) + Canvas-Menu 고정 높이`**.
- **평소(세로 공간 충분)**: 좌우 패딩 20px 유지.
- **예외(가로가 넓어 세로 공간 부족)**: 12px gap 우선 보장 위해 캔버스 축소, 좌우 패딩 20px 초과.
- 내부 요소: 캔버스 크기 변화에 **비례하여 동일 비율 스케일**.

## Background-Dot-Grid (v0.2 신설)
- **점 스펙**: 지름 2px, 색상 Gray-100, 간격 20px(가로/세로 동일).
- **배치**: 앵커 화면 좌상단 (0,0)부터 20px 간격 타일링. 화면 크기 변해도 **점 크기·간격 고정, 개수만 증가**(스케일 X).
- **적용 범위**: 화면 전체(상단바·하단바·캔버스 포함) 뒤에 동일하게 깔림. **캔버스 영역**은 사용자 지정 배경색이 dot grid를 덮어 **가려짐**, **캔버스 밖 여백**은 배경색이 없어 **그대로 노출**.

## Background Blur (v0.1) — 폐기됨
> ✅ [2026-09-21] **존폐 미결 해소.** [[기능정의서-v7]] 전재 v0.3이 "구 Background Blur 정책은 폐기"를 **명시**했다. 병존이 아니라 Dot Grid로의 **대체**다. 아래 조항은 이력으로만 남긴다.
>
> ⚠️ 다만 v7은 폐기 대상을 "**구 v0.2** Background Blur 정책"이라 지칭하는데, Blur 조항은 **v0.1 소관**이고 v0.2에는 없었다. 판본 번호 오지칭이다 → [[open-questions]]
- (v0.1 §2) 배경 유무·종류 무관, 배경 전체를 덮는 Blur 도형을 **별도 레이어**로 항상 적용. 설정값: Fill `Transparency/Black-25`, Effect `Background blur`, 방식 `Uniform`, 값 `4`. 배경 케이스 목업(물/콘크리트/검정) → [[C-001-캔버스-정책-v0.1]] (`raw/assets/C-001-캔버스-background-case.png`).

## v0.3 전언 (원본 미수집)
> 아래는 [[기능정의서-v7]] `기타` 컬럼이 전하는 v0.3 내용이다. **정책서 원본이 `raw/`에 없으므로 현행 규격으로 인용하지 않는다.** 위 v0.2 조항과 어긋나는 항목은 ⚠️로 표시했다.

- **Dot Grid 수치 변경**: 적용 범위가 화면 전면 `375×812`, 도트 간격 **22px**(x·y 동일), 도트 크기 **2×2**.
  - > ⚠️ [2026-09-21] v0.2는 **간격 20px·지름 2px**다. 간격이 20 vs 22로 어긋난다 → [[open-questions]]
- **캔버스 비율 표기**: Canvas-Area가 **9:16** 영역이라고 적는다.
  - > ⚠️ [2026-09-21] v0.2는 같은 대상을 **16:9**로 적는다. 세로 모드 전용이므로 9:16이 실제에 맞아 보이나, 두 문서의 표기가 반대다 → [[open-questions]]
- **탭바 개념 삭제**: C-001 3탭 모드 스위칭(파르페 홈 / 쌓기 / 배경)이 폐기됐다. v0.2가 이미 "별도 탭바 없음"으로 정리한 방향의 종결이다(상충 아님).
- **Canvas-Menu 2뎁스 신설**: "토핑 추가 +" 탭 시 메뉴가 `335×44` → `335×132`로 확장되고 위치가 `y=596` → `y=508`로 위로 펼쳐지며 Canvas-Area 하단 88px를 덮는다. 순서는 ① 카메라로 촬영(C-101) ② 갤러리에서 선택(C-102) ③ 기존 1뎁스 유지.
  - **Dim 범위**: `335×640` 벡터가 Canvas 인스턴스 **내부**에 들어가 딤이 **캔버스 전체(메뉴 포함)로 한정**된다. Top Bar와 Dot Grid 배경은 딤 대상이 아니다. Fill은 `Transparency/Black-25 #0E0E0E40`.
- **Empty State(C-001-Empty)**: Canvas-Area 중앙(x=74, y=302, 187×36)에 2줄 — `아직 캔버스가 비어 있어요 / 첫번째 토핑을 올려 캔버스를 채워보세요`. 저장 아이콘 미노출, Canvas-Menu는 1뎁스 기본 노출.
  - > ⚠️ [2026-09-21] 원본이 **"올려"가 브랜드 동사 규칙(쌓다 확정·올리다 금지)과 충돌**한다며 "쌓아"로 수정을 권고한다. 그러나 **그 브랜드 동사 규칙을 정한 문서가 위키에 없다** → [[open-questions]]
- **날짜바 hidden 처리**: C-304 편집 모드 진입 시 날짜바(Canvas/Button-Date-Select)를 숨긴다.
- **반응형 우선순위**: ① Canvas-Area 비율 무조건 유지 ② 상·하단 gap 항상 동일·최소 12px 보장(375×812 실측 각 16px) ③ 좌우 패딩 20px. v0.2 우선순위와 같은 내용이며 실측값만 추가됐다(상충 아님).
