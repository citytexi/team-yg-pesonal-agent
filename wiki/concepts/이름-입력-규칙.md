# 이름 입력 규칙 (그룹명·닉네임 공통)

[[협업-캔버스-앱]]에서 사용자가 입력하는 이름류(그룹명·닉네임)의 유효성 규칙. 세 정책 문서가 **동일한 규칙 구조**를 공유하며, **최대 글자수만 다르다**.

## 공통 규칙
- **허용 문자**: 한글·영문·숫자·공백(스페이스바). 특수문자·이모지 불가.
- **최소 1자**. 글자 사이 공백(띄어쓰기)도 **1글자로 카운트**.
- **공백**: 맨 앞·맨 뒤 불가. 중간 공백은 **1칸만 허용**, **연속 공백 불가**.
- 통과 예 `홍 길동`(중간 1칸) / 불통과 `   `(공백만)·`길동 `(끝 공백)·`홍  길동`(연속)·상한 초과.

## 적용 대상별 상한

| 적용 대상 | 화면 | 최대 글자수 | 출처 |
|---|---|---|---|
| 그룹명 | A-005 | **10자** | [[A-005-그룹명-정책-v0.1]] |
| 그룹 내 닉네임 | S-102 | **15자** | [[S-102-닉네임-정책-v0.2]] |
| 앱 닉네임 | S-002 | **15자** | [[S-002-앱닉네임-정책-v0.2]] |

- 닉네임은 앱/그룹 공통 15자(규칙 내용 동일, 화면만 다름). 그룹명만 10자.
- **화면별로 문서를 따로 유지한다** — S-102 v0.2와 S-002 v0.2는 규칙 내용이 문자 그대로 같지만(상충 아님), 두 화면이 나중에 갈라질 수 있어 합치지 않는다(2026-07-29 확인). 규칙이 갈리면 이 표의 행이 실제로 달라진다.

## 초기 자동 생성과의 관계
닉네임의 **초기값은 사용자가 입력하지 않는다** — 계정 생성 시 시스템이 부여하고, **사용자가 수정하는 시점부터** 위 유효성 규칙이 걸린다. 즉 **자동 생성물은 유효성 검사를 거치지 않는다.** 생성 규칙·조합 풀·앱↔그룹 값 공유는 별개 층위라 [[닉네임-자동-생성]]이 담당한다.

- 검사를 안 거쳐도 **상한 위반은 구조적으로 불가** — 풀 실측 조합 최대 11자 ≤ 15자([[닉네임-자동-생성]] 길이 상한 검증).
- 자동 생성물은 공백 없이 붙여쓰므로 공백 규칙과도 애초에 무관.
