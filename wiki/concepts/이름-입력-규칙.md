# 이름 입력 규칙 (그룹명·닉네임 공통)

[[협업-캔버스-앱]]에서 사용자가 입력하는 이름류(그룹명·닉네임)의 유효성 규칙. 세 정책 문서가 **동일한 규칙 구조**를 공유하며, **최대 글자수만 다르다**.

## 공통 규칙
- **허용 문자**: 한글·영문·숫자·공백(스페이스바). 특수문자·이모지 불가.
- **최소 1자**. 글자 사이 공백(띄어쓰기)도 **1글자로 카운트**.
- **공백**: 맨 앞·맨 뒤 불가. 중간 공백은 **1칸만 허용**, **연속 공백 불가**.
- 통과 예 `홍 길동`(중간 1칸) / 불통과 `   `(공백만)·`길동 `(끝 공백)·`홍  길동`(연속)·상한 초과.

## 적용 대상별 상한

| 적용 대상 | 화면 | 최대 글자수 | 출처 |
|---|---|---|---|
| 그룹명 | A-005 | **10자** | [[A-005-그룹명-정책-v0.1]] |
| 그룹 내 닉네임 | S-102 | **15자** | [[S-102-닉네임-정책-v0.2]] (v0.2 현행) |
| 앱 닉네임 | S-002 | **15자** | [[S-002-앱닉네임-정책-v0.1]] · [[S-102-닉네임-정책-v0.2]] |

- 닉네임은 앱/그룹 공통 15자(규칙 내용 동일, 화면만 다름). 그룹명만 10자.
- 앱 닉네임 유효성 규칙은 두 문서에 동일 내용으로 실려 있다(S-002 v0.1 / S-102 v0.2 §3). **상충 아님** — 문구까지 같다. 자동 생성 규칙만 S-102 v0.2 단독.

## 앱 닉네임 초기 자동 생성 (v0.2 현행, [[S-102-닉네임-정책-v0.2]])
유효성 규칙과 **별개 층위**다. 사용자가 입력하는 게 아니라 시스템이 부여한다.

- 계정 생성 시 **1회**, **형용사/동사 + 파르페 재료** 랜덤 조합 → 앱 닉네임 자동 부여.
- 조합 형식 = **공백 없이 붙여씀**(`녹는딸기`, `몽글한푸딩`) → 공백 규칙과 애초에 무관.
- **즉시 저장, 이후 재계산 없음.**
- 단어 풀 = 형용사/동사 **100개** × 파르페 재료 **30개**(조합 3000). 목록 자체는 노션에만 있고 **미수집** → [[open-questions]].
- **적용 순서**: 계정 생성 = 자동 생성 규칙 우선 → **사용자가 수정하는 시점부터** 위 유효성 규칙 적용. 즉 **자동 생성물은 유효성 검사를 거치지 않는다.**

## 미결
- **자동 생성 결과가 15자를 넘을 수 있는지** 미정 — 단어 길이 상한이 규정돼 있지 않고 자동 생성물은 유효성 검사 밖 → [[open-questions]].
- **금칙어** 규칙 미정.
- **그룹 내 닉네임 중복** 처리 미정([[기능정의서-v5]] S-102 언급). ([[open-questions]] 후보)
