# 이미지 렌더링 정책 (공용)

[[협업-캔버스-앱]]에서 **이미지를 단독으로 화면에 노출할 때** 공통 적용하는 렌더링 규칙. 특정 화면 번호에 종속되지 않는 **공용 정책** — 촬영 확인(C-101-confirm)·불러온 이미지 확인(C-102-confirm)·누끼 결과 등에 공통 적용. 원본 [[C-103-이미지-렌더링-정책-v0.1]](2026-07-09).

## 최대 렌더링 영역 (Max Bounding Box)
- **최대 너비** = `Device Width − 40px` (좌우 패딩 각 20px).
- **최대 높이** = `Device Height − (상단바 영역 + 10px) − (하단 버튼 영역 + 16px)`.

## 원본 비율에 따른 조건부 분기
이미지를 Max Bounding Box에 맞출 때, **너비·높이 중 어느 쪽이 먼저 한계에 도달하는지**로 분기.

### Case A — 가로가 꽉 참 (가로형·정방형)
- **조건**: 렌더링 시 **너비가 최대 너비에 먼저 도달**.
- **노출**: 배경 컨테이너·테두리 **없이 원본 이미지 단독 노출**.
- **사이즈**: 좌우 패딩 20px 유지, **너비 100%** 렌더링.

### Case B — 세로가 꽉 참 (세로형, 좌우 너비 남음)
- **조건**: 렌더링 시 **높이가 최대 높이에 먼저 도달**하여 좌우 너비가 남음.
- **노출**: 빈 공간을 채우는 **흰색 배경 컨테이너 생성 + 테두리**.
- **컨테이너 규격**: 너비 `Device Width − 40px`(가득), 높이 = **렌더링된 이미지 높이와 동일**.
- **정렬**: 컨테이너 내부에서 이미지 **좌우 정중앙(Center)**.
- **테두리**: 이미지 자체가 아닌 **흰색 컨테이너 외곽선에만 `Gray-500` 1px 스트로크**.

## 관련 정책 — 누끼 캔버스
- [[누끼-따기]]의 **누끼 캔버스 생성 규격**(C-103-Selected, [[C-103-Selected-누끼-이미지-정책-v0.1]])은 위와 **동일한 Max Bounding Box 공식**을 쓰되, 일반 이미지 단독 노출(Case A/B)이 아니라 **객체+여백 캔버스를 Aspect Fit(`contain`)** 으로 렌더한다. 별개 정책(상충 아님).
