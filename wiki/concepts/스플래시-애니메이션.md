# 스플래시 애니메이션 (A-001)

[[협업-캔버스-앱]] 실행 직후 A-001에서 재생하는 **로고 Lottie 애니메이션**. [[기능정의서-v6]]이 A-001을 "스플래시 노출 → 인증 토큰/버전 체크 → 분기" 한 줄로만 규정해 온 자리에, [[A-001-스플래시-정책-v0.1]]이 실물 규격을 채웠다. 분기 로직(토큰 유효 → G-001 / 미로그인 → A-002)은 여전히 기능정의서 소관이고 이 개념의 범위가 아니다.

## 규격 (v0.1 현행, [[A-001-스플래시-정책-v0.1]])

| 항목 | 값 |
|---|---|
| 총 길이 | 3.5초 |
| 프레임레이트 | 60fps |
| 배치 | 중앙 정렬 |
| 에셋 | 로티 1종(캡션 `Lottie-Logo`, 파일명 미기재). 로고 = `Parfait` 적색 글자 |

## 타임라인

| 구간 | 동작 |
|---|---|
| 0.5s부터 0.2s 간격 | 글자 **7개**(`P` `a` `r` `f` `a` `i` `t`) 순차 팝인 — scale 1.1 → 1, opacity 0 → 100, **spring** |
| 2.1s ~ 3.0s | 하단 획 **왼쪽 → 오른쪽 드로잉** — trim path 0 → 100% |
| 3.0s ~ 3.5s | **홀드 후 루프** |

- 마지막 글자 팝인 시작 = 0.5 + 0.2 × 6 = **1.7s**. 획 드로잉(2.1s)과 겹치지 않아 원문 수치는 정합한다.

## 최소 노출 시간
- **3.5s 보장**. 앱 초기화가 더 빨리 끝나도 스플래시를 3.5s 동안 유지한다. 짧으면 애니메이션이 중간에 잘린다.
- 원문이 유일하게 경고 기호를 붙인 조항이다. 초기화가 3.5s보다 오래 걸리는 경우는 **홀드 후 루프**가 받는다.
- [[공통-로딩]]에는 이런 최소 노출 시간 규정이 **없다**(같은 작성자·같은 날짜 문서인데도) → [[open-questions]]

## 미결
- **로티 파일명·로고 에셋 크기·스플래시 배경**이 v0.1에 없다 → [[open-questions]]
- **라이트·다크 대응 여부**가 없다. 에셋 1종만 언급되며, 2종을 두는 [[공통-로딩]]과 대비된다 → [[open-questions]]
- 로고 문자열 `Parfait`이 **정식 제품명인지** 확정되지 않았다 → [[open-questions]]
