# 누끼 따기

사진에서 피사체만 남기고 배경을 제거해 투명 PNG를 만드는 처리. [[토핑]] 생성의 핵심 단계(C-103).

## 동작
- 입력: 촬영([[카메라-뷰파인더|C-101]]) 또는 갤러리(C-102) 이미지.
- 처리: 피사체 마스킹 → 투명 PNG 생성.
- 확인/결과 화면의 이미지 노출은 [[이미지-렌더링-정책]](공용) 따름 — 가로/정방형 단독 노출 vs 세로형 흰 컨테이너+테두리.
- 성공/실패 분기. 실패 시 재시도 또는 원본 사용 옵션, 처리 시간 초과 시 안내.

## 버전별 보강
- [[기능정의서-v5]]에서 다중 검출 대응 서브 화면 추가:
  - `C-103-loading`: 처리 중. 누끼가 **다중으로 잡히면** C-103-select로, 단일이면 C-103으로.
  - `C-103-select`: 여러 피사체 중 대상 선택.
  - `C-104`: 수동 누끼 편집(자동 결과 보정) → 렌더링·제스처·브러시 규칙은 [[누끼-편집]].

## 누끼 캔버스 생성 규격 (C-103-Selected, v0.1)
누끼 대상 선택(C-103-Selected) 후, **객체만 잘라내지 않고 여백을 포함한 '캔버스'를 생성**해 **C-103~C-105에 동일 스케일로 전달**한다(이후 영역 채우기·테두리 편집 용이). 원본 [[C-103-Selected-누끼-이미지-정책-v0.1]].
- **기준 영역**: 대상 객체의 **최소 바운딩 박스**(타이트한 점선).
- **안전 여백(Safe Margin)**: 바운딩 박스 상하좌우 **+20%**(또는 지정 고정 px) 추가.
- **가장자리 예외**: 여백만큼 뻗을 사진 데이터가 없으면 부족분을 **투명 픽셀(Alpha 0%)로 강제 확장** → 캔버스 크기 동일 유지.
- **화면 노출(C-103~C-105)**: 캔버스 전체(객체+여백) 비율 100% 유지, [[이미지-렌더링-정책|Max Bounding Box]](`DW−40` / `DH−상단UI-10−하단UI-16`) 안에 **Aspect Fit(`object-fit: contain`)** + 정중앙 배치. (공용 [[이미지-렌더링-정책]]과 Max Bounding Box 공식 공유, 상충 아님.)
